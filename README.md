# MarimeTech Solutions Website

A focused, responsive Next.js website for MarimeTech Solutions Inc., configured for Netlify.

## Pages

- Home
- About
- Services
- Founder
- Contact
- Custom 404 page
- Static sitemap and robots.txt

## Netlify settings

- Build command: `npm run build`
- Publish directory: `out`
- Node version: 20

The repository includes `netlify.toml`, so Netlify should detect these settings automatically.

## Contact form

The form uses Netlify Forms and sends enquiries for MarimeTech Solutions. After deployment:

1. Open the project in Netlify.
2. Go to **Forms**.
3. Confirm that the `contact` form appears.
4. Add an email notification for `info@marimetechsolutions.com`.
